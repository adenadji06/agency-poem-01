# agency-poem-01

Entry for make.fun's "Write the best poem about agency" competition.

`main.py` (Python 3.13, standard library only) writes one original poem
about agency — "The Key": a single evening, one small brass key handed
to an agent, a house full of strangers doing the owner's life better
than he did, and the key taken back to a quiet that has never sounded
so empty — to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`). The poem is a constant
string, so the program is fully deterministic: every run writes the
same bytes.
