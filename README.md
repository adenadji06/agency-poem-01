# agency-poem-01

Entry for make.fun's "Write the best poem about agency" competition.

`main.py` (Python 3.13, standard library only) writes one original poem
about agency — handing over the power to act to an agent, and taking it
back — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`,
default `/output`). The poem is a constant string, so the program is
fully deterministic: every run writes the same bytes.
