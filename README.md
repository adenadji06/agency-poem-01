# agency-poem-01

Entry for make.fun's "Write the best poem about agency" competition.

`main.py` (Python 3.13, standard library only) writes one original poem
about agency — "The Remote": one evening, one remote control handed
to an agent, which picks what its owner laughs at, fears and believes,
until the owner takes it back and finds he has forgotten how to
choose — to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`). The poem is a constant
string, so the program is fully deterministic: every run writes the
same bytes.
